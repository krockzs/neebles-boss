# N.E.E.B.L.E.S. Boss 1.0.26

Boss 1.0.26 closes the Point 1 + Point 2 source architecture for governed module material and persistent module runtime behavior.

This release adds and certifies:

- persistent authenticated MaterialBinding for installed module material truth;
- independent ephemeral RuntimeLease creation for `modules.runtime` execution;
- Essential + per-module delta composition without a productive mutable shared module rootfs;
- 59-DEB Essential reference layer plus 32-DEB Test Module delta;
- Tray contracts with a generic module-declared `construction_step`;
- Tray-provider birth through Construction, `modules.runtime`, certified world resolution and RuntimeLease;
- removal of direct host Tray-provider execution;
- strict desktop-session authority for session-local readonly resources such as the Tray socket;
- Workspace re-authentication of session readonly grants;
- domestic execution environment sealing to the `NEEBLES_*` namespace;
- rejection of host execution injection through PATH, LD_PRELOAD, LD_LIBRARY_PATH and PYTHONPATH;
- PID-incarnation ownership using pid + start_time_ticks;
- governed process-group ownership for persistent Tray execution;
- fail-closed signaling when authenticated process ownership can no longer be proven;
- kernel SO_PEERCRED validation of the real Tray provider process;
- Registry pinning to the final immutable Point 2 Test Module revision.

The architecture preserves the core law:

Boss governs generic capabilities. CUSTOM V2 certifies material, worlds and Construction. N.E.E.B.L.E.S. OS owns platform authority. Modules remain technology-specific consumers outside the Boss core.
