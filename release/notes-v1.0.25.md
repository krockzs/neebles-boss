# N.E.E.B.L.E.S. Boss 1.0.25

Boss 1.0.25 normalizes safe current-directory tar components during native module materialization, accepting standard Debian data.tar root entries while preserving path-escape protections.

This release adds and certifies:

- native controlled module materialization from certified Debian package material;
- separation of package membership and material integrity;
- generic runtime-manifest authority;
- generic dynamic read-only authority;
- explicit Construction runtime authority and world resolution;
- foreground and persistent Construction execution;
- certified desktop-session environment and physical session projection;
- governed desktop UID/GID execution through the certified Boss runtime;
- generic environment transport through the filesystem boundary;
- exact Module IPC socket authority;
- persistent module runtime birth and authenticated Module IPC registration;
- governed Open through Governor -> Lifecycle -> Construction;
- Registry pinning to the immutable Test Module reference revision.

The release preserves the core architectural law:

Boss governs generic capabilities. CUSTOM and Esbirro certify material, worlds and Construction. N.E.E.B.L.E.S. OS owns platform authority. Modules remain technology-specific consumers outside the Boss core.
